# Stage 1 Pipe Puzzle & Door Logic Analysis

## Overview
The Pipe Puzzle in Stage 1 is a multi-layered interaction that, when completed, triggers the opening of the transition doors to Stage 2.

## Current Interaction Flow
1. **Smoke Suppression**: Players use the `SuppressionWheel` to reduce smoke intensity managed by `PipeAllPuzzleController`.
2. **Mini-Game Connection**: Once the smoke is lowered, players solve the `PipeMiniGame2Board` (tile-based connection puzzle).
3. **Puzzle Completion**:
   - `PipeMiniGame2Board` fires `OnSolved`.
   - `PipeAllPuzzleController` catches this, clears all smoke, and fires its own `OnSolved` event.
4. **Door Opening**:
   - `Stage1SlidingDoor` listens to the `OnSolved` events from either the Mini-Game or the Controller.
   - Upon receiving the event, it calls `OpenDoor()` and executes the sliding animation.

## Key Scripts
- **`PipeAllPuzzleController.cs`**: Manages the relationship between the wheel, the smoke intensity, and the mini-game completion.
- **`PipeMiniGame2Board.cs`**: Handles the logic for the tile-based pipe puzzle.
- **`Stage1SlidingDoor.cs`**: Controls the physical movement of the doors and contains the `UnityEvent` listeners for the puzzles.
- **`PipeSystemManager.cs` / `PipeRepairNode.cs`**: An alternative physical repair path based on pressure management (controlled via `PressureValve.cs`).

## Status & Recommendations
### What works:
- The physical door opening is correctly wired to the puzzle completion events.
- The smoke suppression and mini-game dependency is functional in the code.

### What is missing/incomplete:
- **Display Panel Recognition**: The `MainControlSystem.cs` (Display Panel) does **not** currently monitor the pipe puzzle state. It only tracks Battery/Stability. To have the display "recognize" the fix, it needs a reference to the puzzle controller to update its status text.
- **Stage 2 Transition**: Completion opens the door physically, but the actual scene loading or "Stage 2" initialization is likely handled by a separate trigger volume behind the door, not the puzzle script itself.
